
# Práctica de análisis estático con SonarQube

## Objetivo
Identificar y corregir vulnerabilidades de seguridad mediante análisis estático de código (SAST).

## Herramienta
SonarQube Cloud.

## Vulnerabilidad estudiada
Inyección SQL (SQL Injection).

## Procedimiento
1. Crear un código con una consulta SQL vulnerable.
2. Analizar el código con SonarQube Cloud.
3. Identificar la regla de seguridad y la CWE.
4. Corregir la vulnerabilidad.
5. Ejecutar un segundo análisis y verificar la Quality Gate.
